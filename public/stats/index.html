About these numbers

  • Counts are anonymous. No names, emails, IP addresses, cookies or device IDs are recorded, so the site can't tell how many different people visited, only how many times things were used.
  • "Opened" counts every time a set was loaded, including by the person who made it.
  • Days run midnight to midnight, Eastern time. Counting started when this report was added, so earlier activity isn't included.
  • People who block scripts or whose school filters the site aren't counted.
