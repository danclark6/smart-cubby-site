# Reporting a security problem

If you find a way to read, change or delete someone else's flashcard set, see the private stats, or otherwise break the site's protections, please **don't open a public issue**.

Instead, report it privately: go to this repository's **Security** tab and click **Report a vulnerability**. Only the site owner can see these reports.

Please include the steps to reproduce the problem. Don't access or change other people's data beyond what you need to show the problem exists.

Thank you for helping keep students' work safe.
